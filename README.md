# Red Roll

A physics-based 3D rolling platformer inspired by Red Ball. Roll your way to the green goal pad!

## How to Play

1. Open `index.html` in a modern browser (Chrome/Firefox/Edge recommended)
2. Use **WASD** or **Arrow Keys** to roll the ball
3. Reach the green glowing goal pad to complete the level
4. If you fall off, you'll automatically respawn
5. Press **R** to restart after winning

## Features

- **Physics-Based Movement** - Real momentum and rolling physics
- **3D Platforming** - Navigate ramps, platforms, and gaps
- **Smooth Camera** - Third-person camera follows behind you
- **Fall Detection** - Auto-respawn when falling off the level
- **Win Condition** - Reach the glowing goal to complete

## Tech

Built with Three.js for rendering, Cannon-es for physics, pure JavaScript (ES modules).
